Milestone 1 Resubmission - Smart Contract Development Evidence

This resubmission provides the evidence listed in the Milestone 1 Evidence of Completion section:

1. Detailed test results
2. Technical report describing test scenarios
3. Testnet deployment transaction evidence
4. Preview/Preprod transaction IDs demonstrating functionality

The submitted evidence demonstrates the core rolling-loan smart contract mechanism as an atomic refinancing flow. The tested transaction moves an active loan position from the Float Loan smart contract to the Leverage Loan smart contract in a single transaction.

This flow follows the rolling-loan design:
- create a new loan position
- settle the existing loan position using the newly originated loan
- redirect collateral from the existing loan into the new loan position
- avoid a separate manual repayment, collateral withdrawal, and new loan opening process
